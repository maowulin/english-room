# 页面设计图

本目录保存基于原始实作题设计并经确认的首轮高保真页面。

## 页面清单

| 页面 | 文件 | 对应业务能力 |
| --- | --- | --- |
| 大厅与加入房间 | [`01-room-entry.png`](./mockups/01-room-entry.png) | 创建房间、输入房间码、进入语音房间 |
| 房间等待 | [`02-waiting-room.png`](./mockups/02-waiting-room.png) | 玩家席位、准备状态、麦克风检查、开始游戏 |

| 局后评分报告 | [`04-score-report.png`](./mockups/04-score-report.png) | 玩家评分、局内表现、等待、处理中、成功和失败 |

## 视觉方向

- 业务氛围：沉浸式剧本房与专业英语报告结合。
- 主色：深墨绿、薄荷绿和暖白色。
- 信息原则：玩家身份、媒体状态和评分状态必须清晰对应。
- 账号原则：登录和注册保持单一主操作，第三方登录与协议入口明确分层。
- 实现约束：设计图用于确定信息架构和视觉方向，最终客户端需要使用可访问、可测试的原生组件实现。
