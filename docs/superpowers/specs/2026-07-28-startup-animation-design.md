# English Room 启动加载动画规格

## 状态

视觉方案已确认，等待实现前规格复核。

## 目标

在 App 初始化、读取本地会话和建立首屏所需连接期间，展示一个短暂的 English Room 品牌加载层。初始化完成后立即过渡到现有首屏，不改变登录、注册或房间业务逻辑。

## 已确认的视觉方案

- 背景使用现有 English Room 的暖米白色。
- 中心使用深绿色圆角方形标志。
- 标志图形为简洁的对话框轮廓与绿色声音波形，不使用 Emoji、麦克风图标或伪造语音状态。
- 动效顺序为：标志容器汇聚出现 → 对话框轮廓绘制 → 波形点亮 → 极轻微呼吸。
- 下方展示 `A room for your voice`、`English Room`、`Find your voice. Tell the story.`。
- 底部使用细路线表达初始化进度，文案为 `Preparing your room` 和 `Ready soon`。
- 整体保持高保真原型的排版、颜色、圆角和间距。

## 行为要求

- 仅在启动初始化未完成时显示，不作为每次路由切换的固定页面。
- 初始化完成后，启动层淡出并显示当前首屏；默认过渡总时长约 180ms。
- 初始化较慢时停留在最终加载帧，不循环播放、不快速闪烁、不阻塞用户继续使用。
- 启动动画不得等待网络评分、TRTC 入房或报告生成完成；它只负责 App 启动阶段的基础初始化。
- 重复启动时必须重新触发一次进入动画，但不能创建重复定时器或泄漏动画监听。
- 支持 `prefers-reduced-motion` 对应的系统减少动态效果设置：直接显示稳定标志和加载层，并保留淡出/显示逻辑。
- Android 返回键、系统手势和现有导航行为不受启动层影响；启动层可见时不应出现可点击控件。

## 实现边界

- 入口接入 `apps/mobile/src/app/_layout.tsx` 或 `apps/mobile/src/app/index.tsx` 的 App 根初始化层，具体位置以现有 Expo 路由生命周期为准。
- 使用现有正式图标体系或新增可复用的品牌标志组件；不得把 HTML 原型作为静态 WebView 或背景图嵌入 App。
- 使用 Expo v57 兼容的 React Native 动画能力，避免引入不必要的新依赖。
- Expo 原生静态 splash 仍负责系统启动白屏；本功能是系统 splash 结束后的 App 内初始化过渡。
- 现有 `AppIcon` 产品图标体系保持不变；启动品牌标志可以作为独立的 `BrandMark` 组件复用到登录页小标志。

## 可访问性与响应式

- 使用 `accessibilityLabel="English Room"`，加载层设置为非交互状态。
- 适配窄屏和大字体，不得让品牌名、标语或加载文案发生横向溢出。
- 动画不依赖固定屏幕高度；安全区由根布局统一处理。

## 测试与验收

新增或更新测试覆盖：

1. 初始化未完成时加载层可见，初始化完成后加载层不可见且首屏可见。
2. 初始化较慢时加载层保持最终帧，不自动跳转或循环。
3. 重复挂载/卸载不会遗留定时器或动画监听。
4. 减少动态效果设置下仍能完成显示与淡出。
5. 390×844、430×932 手机视口下无溢出、遮挡或不可点击区域。

实现后必须运行：

- `npm test -- --runInBand`
- `npm run typecheck`
- `npm run lint`
- `git diff --check`
- Web 手机视口截图验证
- 真机 release APK 启动验证

## 不在本次范围

- 不修改登录/注册文案和认证流程。
- 不改变 TRTC、录音、评分和报告轮询逻辑。
- 不把启动动画用于等待语音连接、录音上传或 AI 评分。
- 不替换系统原生 App icon；本次只增加 App 内启动过渡。
